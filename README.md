# dotBeats S14 · 24 mm

[Assembly viewer](https://evannnx.github.io/dotbeats-case-studio/) · [STEP and STL package](https://evannnx.github.io/dotbeats-case-studio/assets/dotBeats-S14.zip)

PCB mounted to the base. Six front keys, two side switches with integral 2 mm cradle walls and lid retention frames, and a continuous curved battery cradle. Enclosure: 86.5 × 140 × 24 mm, excluding button heads.

The viewer includes exploded views, side-switch installation, solder access and battery insertion. Downloads contain analytic mechanical STEP, printable STL, reference assembly GLB and validation reports. Electronics are reference meshes, not editable STEP components.

Battery reference: diameter 18.7 × 53.3 mm; cradle diameter 19.3 mm and internal length 53.9 mm. Actual solder joints, wires, FDM tolerances, return and strength require physical fit testing.

Case hardware: four M2.5 × 8 mm screws and four brass heat-set inserts, OD 4.6 × length 4 mm. PCB hardware: three M2.5 × 6 mm screws, nuts, insulating washers and printed centering bushes. Print one side coupon first.

## Development

Run `npm ci`, then `npm run dev`. Build with `npm run build`; publish the resulting files in `docs/` on `main` for GitHub Pages. Older revision assets remain available for existing download links.
